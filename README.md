### Painel de Chamados CFTV
**Análise de dados de suporte técnico (GLPI)**

Projeto de extensão em parceria com o setor de TI de uma prefeitura, analisando chamados da rede de câmeras de vigilância.

**Verificação automatizada de planilhas**

- Distribuição como executável (.exe)

**Stack:** Python, customtkinter
